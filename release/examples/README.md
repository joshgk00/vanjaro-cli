# Release evidence examples

These files demonstrate contract shape only. They are not observed evidence,
cannot close any release gate, and must never be copied or submitted as proof.

All identities, routes, dates, versions, and digests are unmistakable example
values. In particular, the live-shaped files do not claim a real operator or
portal observation: the reserved `example.invalid` host, failed smoke checks,
expired date, and unrestored cleanup make them deliberately unusable as live
release evidence.
